## Flappy Bird
`pip install pygame-ce`

Desktop: `python game.py`

Web build (browser): `pip install pygbag` then `python -m pygbag main.py` → http://localhost:8000

`main.py` is the WebAssembly port of `game.py` (async loop, OGG audio, no `set_timer`).
